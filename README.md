# Facturación Kyra

Repositorio del sistema interno de facturación de Kyra.

## Proyecto activo

El desarrollo actual se encuentra en [`kyra-ipm-v4`](kyra-ipm-v4). Las demás carpetas conservan versiones anteriores como referencia.

## Estructura

| Ruta | Contenido |
| --- | --- |
| `kyra-ipm-v4/` | Aplicación actual en React y Vite |
| `kyra-ipm/`, `kyra-ipm-v2/`, `kyra-ipm-v3/` | Versiones anteriores |
| `files/` | Documentación, imágenes y archivos de apoyo |

## Inicio rápido

Requiere Node.js 18 o superior y npm.

```bash
cd kyra-ipm-v4
npm install
npm run dev
```

## Comandos

Desde `kyra-ipm-v4/`:

```bash
npm run dev       # Entorno de desarrollo
npm run test:run  # Pruebas
npm run build     # Compilación de producción
```

La documentación específica del proyecto está en [`kyra-ipm-v4/docs`](kyra-ipm-v4/docs).
